# Expense-Tracker-2.0-Python
Expense Tracker 2.0 is a Python-based console application developed as part of the Python Programming Internship at Maincrafts Technologies. The application helps users manage daily expenses efficiently by categorizing expenses, tracking spending, and generating monthly reports.

🚀 Features

- Add new expenses
- Store expense details in a CSV file
- Categorize expenses (Food, Travel, Shopping, etc.)
- View all recorded expenses
- Search expenses by category
- Calculate total spending per category
- Generate monthly spending reports
- Simple menu-driven interface

---

🛠️ Technologies Used

- Python 3
- CSV Module
- OS Module
- Datetime Module

📋 How It Works

1. User selects an option from the menu.
2. Expense details are entered and saved in a CSV file.
3. Expenses can be viewed, searched, and analyzed.
4. Monthly and category-wise reports are generated automatically.
